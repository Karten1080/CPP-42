07. veille cve

Veille CVE

CVE-2024-6387 CVSS 8.1 2024-07-01

OpenSSH — regreSSHion, Race Condition pre-auth RCE

Race condition dans le handler SIGALRM de sshd sur les systèmes Linux glibc. La vulnérabilité est déclenchée par l'appel de fonctions non-async-signal-safe depuis un signal handler. Elle permet une exécution de code à distance non authentifiée, exploitation difficile mais démontrée. Impact massif vu l'ubiquité d'OpenSSH. En pentest, pertinent pour les cibles Linux exposant SSH non patché. Patch : OpenSSH ≥ 9.8p1.

CVE-2024-3400 CVSS 10.0 2024-04-12

PAN-OS — Command Injection pre-auth RCE (GlobalProtect)

Injection de commandes OS dans la fonctionnalité GlobalProtect de Palo Alto PAN-OS. Exploitable sans authentification via une requête HTTP malformée ciblant le daemon GPGW. Mène à une exécution arbitraire en root sur le firewall. Exploitée activement dans la nature (APT UTA0218) pour déployer des backdoors. CVE critique pour les équipes SOC : indicateurs de compromission documentés par Volexity.
